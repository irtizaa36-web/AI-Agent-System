# Agency Agents

289 specialized Claude Code subagent personas, sourced from
[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT licensed) and installed here so they're available project-wide to
anyone working in this repo — not just one machine's local Claude Code
config.

Covers: academic, design, engineering, finance, game development, GIS,
healthcare, marketing, paid media, product, project management, research,
sales, security, spatial computing, specialized/support roles, strategy,
and testing.

## Using one

In Claude Code, just say something like "activate Frontend Developer mode"
(or any other agent's name from this directory) and Claude takes on that
persona's role, voice, and process for the rest of the conversation.

## Keeping these up to date

These are a point-in-time copy, not a live link to the source repo. To pick
up upstream updates, re-run the same copy step against a fresh clone of
`msitarzewski/agency-agents` (see the source repo's own README for its
current directory layout) and commit the result.
